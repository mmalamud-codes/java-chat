This is a Java chat application that I created to gain a deeper understanding about networking and how chat applications work. 
In this repository, you'll notice that I've used server sockets and sockets to program this, along with OOP programming. Feel free to
make as many changes as you like since there will be a website version coming out soon.

If you are looking to run this, make sure to install the latest version of Java if you haven't done that already. The version that I have currently installed is 25.0.4.1. Also, make sure to open three terminal windows, two for the clients and one for the server, to further run this.
